# Data folder

No real personal data is stored here. Everything is public synthetic data or fictional documents
generated by this project.

| Folder | Content | In Git? | Created by |
|---|---|---|---|
| `raw/nemotron_pii/` | Original dataset files (`train.parquet`, `test.parquet`, about 300 MB) | no | `scripts/01_prepare_data.py` (download) |
| `processed/` | Cleaned and mapped documents: `train.jsonl` (20,000), `validation.jsonl` (2,000), `test.jsonl` (3,000), 33 MB | yes | `scripts/01_prepare_data.py` |
| `extra/org_supplement_raw.jsonl` | The team's 500 extra business documents with company names (source file, only `ORG` labelled) | yes | the team (see `docs/DATASET_UPDATE.md`) |
| `processed/org_supplement_*.jsonl` | The same 500 documents after checking, label completion and a split by template: train 350, validation 50, test 100 | yes | `scripts/05_prepare_org_supplement.py` |
| `synthetic/dev`, `synthetic/test` | 60 fictional evaluation documents (20 dev, 40 test) | yes | `scripts/03_make_synthetic_docs.py` |
| `gold/` | Gold labels for the synthetic documents: `ner_gold.json`, `regex_gold.json` | yes | `scripts/03_make_synthetic_docs.py` |
| `samples/` | Fictional sample files for trying the app (TXT, PDF, one image-only PDF) | yes | `scripts/03_make_synthetic_docs.py` |

## Training dataset

- **Name:** NVIDIA Nemotron-PII
- **URL:** https://huggingface.co/datasets/nvidia/Nemotron-PII
- **License:** Creative Commons Attribution 4.0 International (CC BY 4.0)
- **Language:** English
- **Size:** 200,000 documents (100,000 in each file), 55 label types, 58 domains
- **Nature:** fully synthetic, generated with NVIDIA NeMo Data Designer; labels are created during generation
- **Limitations:** synthetic text, US-centric personas, English only, only inserted values are labelled
- **Citation:** Steier, A., Manoel, A., Haushalter, A., Van Segbroeck, M. (2025). *Nemotron-PII: Synthesized Data for Privacy-Preserving AI.* NVIDIA.

## Format of the processed files (one JSON object per line)

```json
{"uid": "...", "domain": "...", "document_type": "...", "document_format": "structured",
 "locale": "us", "text": "...",
 "entities": [{"start": 3, "end": 14, "label": "PERSON"}],
 "regex_entities": [{"start": 40, "end": 58, "label": "EMAIL"}]}
```

`entities` are used to train and test the AI model. `regex_entities` are never used for training;
they are an independent gold set for testing the rules.

## Format of the gold files

```json
{"doc_001": {"split": "test", "template": "formal_letter",
             "entities": [{"label": "PERSON", "start": 20, "end": 31}]}}
```

Offsets are character positions in the canonical text of `synthetic/<split>/<doc id>.txt`
(start inclusive, end exclusive).
